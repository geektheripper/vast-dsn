# Vast DSN

DSN (data source name) for anything.

## DSNs

| DSN                               | Example                                                                                           |
| --------------------------------- | ------------------------------------------------------------------------------------------------- |
| [S3](s3_dsn/README.md)            | `s3://[<credentials>@]<endpoint>[:(port)]/<bucket>/<key>[?region=<region>&querys...]`             |
| [Redis](redis_dsn/README.md)      | `<protocol>://[<credentials>@]<host>[:(port)][/<db>[/<key-prefix>]][&querys...]`                  |
| [Elasticsearch](es_dsn/README.md) | `<http\|https>://[<credentials>@]<endpoint>[:<port>][?index=<index>&index_prefix=<index_prefix>]` |
